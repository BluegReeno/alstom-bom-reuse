# DECISIONS

The human decisions this build rests on, **as they stand**: what was decided, why, and whether it
overruled a proposal made by the AI. One line per decision, final form only — a decision a later
one changed is rewritten in place, one it replaced is removed, and the git history of this file
keeps the path. The numbers are identifiers cited across the repository (`DECISIONS.md 29`,
`Dec. 17`), so they never move: a gap in the sequence is a decision that no longer stands.
Agents do not write here on the human's behalf.
